# Лабораторная работа № 2 — вариант 6

Генетический алгоритм составляет месячный план закупки расходных материалов. Ограничения: общий бюджет и минимальный остаток каждого материала на складе.

Проект не использует внешние библиотеки: достаточно Python 3.10 или новее.

## Состав проекта

- `generate_data.py` — создаёт входные данные с фиксированным seed 2026;
- `data/materials.json` — 30 сгенерированных позиций и бюджет;
- `ga_procurement.py` — сам генетический алгоритм и один запуск;
- `run_experiments.py` — серия из 20 запусков, сравнения и файлы результатов;
- `config.json` — все основные параметры алгоритма;
- `report.md` — краткий отчёт;
- `outputs/` — результаты уже выполненной серии экспериментов.

## Быстрый запуск

Из папки проекта выполните:

```bash
python3 generate_data.py
python3 run_experiments.py
```

Первая команда заново создаст тот же `data/materials.json`. Вторая перезапишет результаты в `outputs/`.

Для одного запуска ГА:

```bash
python3 ga_procurement.py --seed 1000 --strategy repair --mutation redistribute
```

Параметр `--strategy` принимает `repair` (ремонт ограничений) или `penalty` (штрафы). Параметр `--mutation` принимает `redistribute` (перенос количества между двумя позициями) или `reset` (случайная смена одной позиции).

## Результаты

Главные файлы после запуска:

- `outputs/experiment_results.csv` — все 80 результатов: 20 запусков × 4 метода;
- `outputs/summary.csv` — лучшее, среднее, медиана, стандартное отклонение и худший результат;
- `outputs/best_plan.csv` — лучший найденный план закупки в форме таблицы;
- `outputs/solution_examples.csv` — два допустимых и два недопустимых примера;
- `outputs/convergence.svg` — график средней сходимости;
- `outputs/algorithm_scheme.svg` — блок-схема генетического алгоритма;
- `outputs/run_information.json` — seeds, параметры и одинаковый бюджет оценок.

Текущий набор результатов получен 20 запусками с seeds от 1000 до 1019. Они воспроизводятся командами выше.
